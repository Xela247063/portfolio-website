# Alex Maharjan | Portfolio

A simple, static portfolio site. No build step, no frameworks: just HTML and CSS.

## What's inside

```
portfolio/
├── index.html
├── style.css
├── README.md
└── images/
    ├── hero-placeholder.svg
    └── hero.jpg        <- add your own photo here
```

## Before you upload

1. **Add your photo.** Save it as `images/hero.jpg`. A portrait shot works best, roughly 4:5 (for example 800 x 1000 px). Until you add it, the green placeholder shows.
2. **Update your contact details** in the Contact section of `index.html` (email, LinkedIn, GitHub).
3. Read through the text once and change anything that doesn't sound like you.

## Put it on GitHub

1. Create a new repository on GitHub. For a free personal site, name it `your-username.github.io`.
2. Upload the contents of this folder (not the folder itself) so that `index.html` sits at the top level of the repo.
3. Go to **Settings > Pages**, set the source to your `main` branch and the `/ (root)` folder, then save.
4. After a minute or two the site is live at `https://your-username.github.io`.

If you name the repo something else, the site will appear at `https://your-username.github.io/repo-name`.
